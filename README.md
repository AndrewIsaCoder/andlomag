# 🛍️ andlomag

**andlomag** is a simple online store project built entirely with **HTML**, **CSS**, and **JavaScript**.  
I created it to practice front-end web development and to better understand how e-commerce websites are structured.  
The project includes pages for a product catalog, product details, a shopping cart, and a basic admin panel.  
It’s fully static (no backend) and designed to be clean, minimal, and easy to extend later with dynamic features.

---

## ✨ Features

- Product catalog (main page)  
- Product details page  
- Shopping cart page  
- Simple admin panel  
- Custom design with pure CSS  
- Interactive elements powered by JavaScript
